# Tomb Navigation and Contract Management System

A Flutter-based capstone project developed using FlutterFlow.

## Project Overview
The Tomb Navigation and Contract Management System is designed to help cemetery administrators manage burial locations, contracts, visitors, and transactions efficiently while providing users with easy navigation and record access.

## Technologies Used
- Flutter (FlutterFlow)
- Firebase (Authentication, Firestore, Storage, Functions)
- Android & iOS support
- Web support

## Getting Started
This project is built to run on the Flutter **stable** release.
